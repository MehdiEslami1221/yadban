# Usage

Choose **New reminder**, enter a title, choose a category and select a due date. Amounts are optional and use toman. Date entry is Gregorian even in Persian mode. The timezone shown below the fields belongs to the current device.

Choose an alert lead time. For a series, select weekly, monthly or yearly recurrence and the number of occurrences. Each occurrence can be edited and completed independently.

The check button marks a record complete. Completed records appear in the Completed view and can be restored with Undo. The row menu offers editing, calendar export and deletion. Deletion asks for confirmation and has no in-app recovery.

Upcoming totals cover pending due dates in the next 30 days; overdue records are separate. Marking a reminder complete does not verify a real payment.

Switch languages using the language button. Persian mode uses RTL layout and a Persian calendar. Day filters use the current device timezone.

Sign in on other devices with the same deployment URL/password. Reload to retrieve changes made elsewhere and enable notifications on each device separately.

ICS files are snapshots with alarms. Check your calendar's import behavior; repeated imports may create duplicates. JSON export provides portable reminder records but has no one-click import. Use private D1 backups for complete recovery.
